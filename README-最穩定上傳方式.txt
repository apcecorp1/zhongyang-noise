V5.1 圖片內嵌版（最穩定）

這個版本已把每一頁需要的工程照片直接嵌入 HTML 裡，
不再依賴 images/ 資料夾，也不會因為圖片路徑、大小寫、
資料夾位置不同而出現白框。

GitHub 上傳方式：
1. 解壓縮 ZIP。
2. 把裡面的所有 .html 檔案直接拖到 Repository 根目錄。
3. 覆蓋同名檔案。
4. 原本 images/ 資料夾可以保留，不必刪除。
5. assets/ 也不用依賴，因為 CSS 已一起嵌入頁面。
6. 等 GitHub Pages 更新後重新整理網頁。

注意：
因為照片直接包在 HTML 裡，所以 index.html 檔案會比以前大，
但這是目前最不容易出錯的方式。
